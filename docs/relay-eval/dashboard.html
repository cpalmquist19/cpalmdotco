    How to read this

    Metrics
    Limits to keep in mind
    • Each task is repeated only a few times, so a gap of one or two runs is noise. The whiskers show how big a gap needs to be.
    • The task set is small and mostly easy. Tasks everyone passes tell you nothing about which model is better.
    • The suite measures this agent's tools and prompts on small tasks. It is not a general benchmark of the models.
    • Runs that hit a rate limit or lost connection are retried, but a final infrastructure error still counts as a failed run.
    • Costs come from the token counts each provider reports, priced from evals/pricing.json. Costs marked ~ are estimates rebuilt from the saved transcripts: they cannot see hidden reasoning tokens (so reasoning models are undercounted) and assume no prompt caching (so providers that cache automatically are overcounted). Treat them as rough, and rely on reported figures from runs made after usage tracking was added.
